# Features built

How it is put together: [[architecture]].

- **Landing page** (`/`): "Glass Lanterns" look. A floating Liquid Glass nav (real refraction), the heading "See every agent working.", and sample agents as glass tiles: lit from inside when working, a dashed outline when idle, with a red seal on the last to answer (labelled sample data). The tiles rise and light in turn, then one flares as its numbers count up and the seal glides to it. Then a short "what it does" list and the stack. Replaced the old "AI Automation Agency" copy.
- **Auth**: sign up, email OTP verification (with resend), sign in, forgot and reset password. Change password and profile are behind a login.
- **Add/edit agent dialog** is split into Identity, Model and Behaviour. A provider picker (OpenAI, Gemini, DeepSeek) shows whether a key is ready, creativity has a Precise/Balanced/Creative readout (disabled for OpenAI models that set their own), and reply length has presets. It asks the backend for the latest models of the chosen provider (using the user's key) and defaults a new agent to the newest; with no key it shows the built-in list and says to add a key in Profile.
- **Agents** (`/app/agents`): an empty state ("No agents yet" with a create button and a key hint; a separate "No agents match" state for searches), a banner and a per-card "No OpenAI/Gemini/DeepSeek key yet. Add one" link to Profile when an agent's provider has neither a user key nor a shared key (hook `use-api-keys`); create, edit, delete, favourite; system prompt, provider and model (OpenAI GPT-6, Gemini 4 and 3.x, DeepSeek V4; built-in fallback lists live in `frontend/lib/providers.ts`), temperature and max tokens.
- **Chat** (`/app/chat`): pick an agent, streaming replies (SSE) rendered as Markdown (lists, tables, links, highlighted code blocks with a copy button; `components/markdown.tsx`, replies only, your own messages stay plain), saved conversations that can be renamed and deleted.
- **Analytics** (`/app/analytics`): metric cards (large tabular numbers), time ranges, per-agent filter, line, area and bar charts, live updates over the `/metrics` socket with pause and play.
- **Profile** (`/app/profile`): account details, password change and an **API keys** card where each user saves, replaces or removes their own OpenAI, Gemini and DeepSeek keys (shown only by last four characters). Chat uses the user's key, falls back to a shared server key if one is configured, and otherwise tells the user to add one (with an Open Profile action).
- **Shell**: collapsible sidebar with a red seal and highlight that glide between routes, glass chrome, top bar, mobile drawer. Pages fade and rise on route change; metric numbers count up; agent cards and chat messages enter with a short rise.
- **Sign-in uses HttpOnly cookies with silent refresh:** a 15-minute access token is renewed quietly with a rotating refresh token, so people stay signed in for a day, or 30 days with a "Remember me" checkbox on the sign-in page. When the whole sign-in ends the app shows "Your session has ended" with a button to sign in again; visiting `/app` while signed out goes straight to sign-in. Logout, password reset and password change end sign-ins on the server.
